# 运行手册草案

当前只有开发诊断 CLI，不存在 `run`、`resume` 或真实 Agent 调度命令。后续实现后更新本手册，不能按目标接口虚构可执行命令。

## 启动前

确认受信任的 Supervisor 版本、任务包摘要、干净基线、运行配置、预算、必需隔离能力、受保护验收和凭证路由。能力缺失时阻断。

Agent/模型认证在执行机器安全配置；只检查名称、存在性和所需操作，不打印环境或认证文件。云平台已有 Git 代理认证时直接验证所需只读 Git 操作，不额外索要 token。

## 运行中

每次 attempt 记录启动意图、实际执行身份、事件序列、输出限制和代码快照。用户取消时先停止新的动作，再回收当前进程树，记录是否真的成功。不要通过关闭输出或杀掉 Supervisor 本身掩盖未回收子进程。

## 恢复与异常

使用 `docs/workflow.md` 的恢复协议。证据不齐、数据库/快照冲突或外部副作用未知时 NEEDS_HUMAN。禁止用 reset/clean 删除证据或覆盖用户改动。

## 结果与保留

最终报告包含状态、任务和快照标识、模型/Worker/平台、检查结果、审核独立性、变更范围、耗时和未知 usage。只保留必要且脱敏的内容；原始输出默认关闭，启用前明确访问控制和保留期。

完成不等于合并或发布。Supervisor 默认不 push，正式合并/部署由单独的用户授权决定。
