# M0 独立验收计划

独立检查已写入 `tests/protected/test_m0_acceptance.py`，固定入口见 api.md，实现者不能修改这两个文件。实现尚未存在时，这些检查应正常收集并失败，不标记 skip/xfail。通过必须在实际实现后重新执行。

| 输入/场景 | 必须验证的行为 |
| --- | --- |
| 子程序分别写 stdout/stderr 后退出 0 | 两路都捕获，身份匹配，实际退出码与 completed 一致 |
| 子程序退出 7 | 保留 7 与错误状态，不声称 completed |
| 不存在的程序/目录 | environment_failure，调用方 cwd 不变，无悬挂进程 |
| 参数含空格、中文与 shell 元字符 | 原样传递，不能发生额外命令执行 |
| 超过 wall timeout | timed_out，耗时在宽限范围，支持平台的子进程树确实终止 |
| 启动前/运行中取消 | cancelled，不启动或回收已启动的进程树，重复取消无额外副作用 |
| 同时洪泛两路输出 | 不死锁，合计内存/输出预算有效，output_limit/truncated 正确 |
| 子程序产生孙进程 | timeout/cancel 后独立检查孙进程是否存活；不支持时明确拒绝相关声明 |
| 退出 0＋错误/残缺 JSON | failed，保留解析错误，不返回假成功 |
| 非零退出＋输出 completed | 仍失败，不信任输出状态 |
| 缺失/未知字段或负 usage | 拒绝或按完整协议报错，不静默填值 |
| 输入 task/run/attempt 与输出不符 | 拒绝过期/错误身份的结果 |
| 环境中有非生产 sentinel secret | 未授权子程序看不到该变量；事件/交付报告不包含哨兵值 |
| 零、负数、NaN/Infinity 预算 | 启动前拒绝，不能无限运行 |

验收不以“Mock 正常结果一次通过”代替失败路径。进程树检查对实际支持的每个平台执行；当前未执行的平台标未运行。

脚手架 tests/protected/test_specs.py 只验证格式，不能替代上述行为验收。命令收集不到 M0 测试或独立验收文件未准备时，本任务不允许 accept。
